# simple_ROBOCOPY_tool
A simple wrapper/encapsulation for the built-in Windows tool ROBOCOPY.
## Command
ROBOCOPY SOURCE DESTINATION /R:5 /W:3 /E /MT
### Compile
Built with Visual Studio Code and WinLibs GCC 16.2.0.

Compiler: WinLibs GCC 16.2.0

Editor: Visual Studio Code

Standard: C23 / GNU C23
#### Final exe
name: cpytool.exe
